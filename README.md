# 📅 Flutter Calendar

Un proyecto corto creado para **probar la tecnología de Flutter**.  
Este calendario permite organizar tareas de manera simple y visual.

---

## ✨ Funcionalidades
- 📝 **Recordar tareas**: agrega tus pendientes fácilmente.  
- 😀 **Emojis e imágenes predefinidas**: personaliza tus tareas con íconos divertidos.  
- ✅ **Marcar como completadas**: gestiona tu progreso de forma clara.  
- ⏰ **Fechas y horas**: asigna tiempos específicos a cada tarea.  

---

## 🚀 Objetivo
Explorar las capacidades de **Flutter** en el desarrollo de aplicaciones móviles y de escritorio,  
experimentando con la gestión de tareas y la integración de elementos visuales.

---

## 🛠️ Tecnologías
- **Framework:** Flutter  
- **Lenguaje:** Dart
